# CIS133 Chapter 7 companion: UX Beyond the Web

## Communication job

By the end, CIS133 students should recognize the interface in the IT field
they plan to enter, sort one decision there into the UX or UI layer, and
score it against the five principles, because the principles from section
7.2 measure every interface a technician ships, not only web pages.

## Teaching plan

- Course level: CIS133, Part III, after section 7.2
- Prior knowledge: UX against UI, the five principles, the sorting test
- Delivery: 25-minute companion segment inside the Chapter 7 class
- Opening problem: an alert at 3:07 a.m. has exactly one user
- Evidence and practice: cybersecurity, network infrastructure, help desk, system administration, hardware, and data examples, one sorting check
- Final application: pairs score one interface from their own field, then the exit ticket

## Visual system

- Palette: `midnight-gold`
- Treatment: ops floor, with rack-unit rule lines, a mounting rail, lit indicators, and monitor-bezel figure frames
- Image source: Codex-rendered flat-vector illustrations in the deck palette, styled after the Chapter 8 set, with no readable words
- Content source: section 7.2 of the CIS133 textbook, extended with field examples
