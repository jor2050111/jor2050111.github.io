Lesson 16.2 · Install paths

Clean wipes the drive. In-place keeps the data.

Clean install

Start from zero

Repartition and reformat the drive, then install. Nothing on the disk survives.

FD-01 takes this path
In-place upgrade

Update what exists

The new OS updates the existing install. User data remains on the system.

In-place upgrade. It updates the existing OS and user data remains on the system. The clean path repartitions and reformats the drive first, so nothing local survives. Back up either way.
