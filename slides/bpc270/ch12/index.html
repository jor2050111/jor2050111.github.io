BPC270 · 12.2
Check: The overnight laptop

Commit: sleep or hibernate for the overnight bag?

Standby: RAM stays poweredHibernate: memory saved to disk, all power off

With a partner: J. Moreno leaves open work on a laptop overnight, and the battery may die before morning. Which power state protects the work, and why?

Hibernate. It saves memory data to disk and removes power from all components, so a dead battery loses nothing. Standby keeps RAM powered, and losing that power loses the open work.
