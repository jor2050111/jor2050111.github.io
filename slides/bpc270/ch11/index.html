Service level agreements

Five nines of uptime leave 5.26 minutes a year.

An SLA defines the metrics of service delivery before any ticket exists.

Internal · between departmentsExternal · an ISP or a CSP
5 nines99.999%5.26 minutes of downtime a year
8 nines99.999999%315.58 milliseconds a year

Each added nine shrinks the allowed downtime. The same math sizes allowed data loss after a disaster.

Categories and severity

Every issue gets a name and a rank.

  • RequestProvision assets, like new accounts or systems.
  • IncidentErrors or unexpected conditions.
  • ProblemIncidents that force reconfiguring the system or network.
SeverityCriticalMajorMinor

Each organization writes its own lists. Best practice: put both in writing.

Complaints are not personalPositive attitude

With a partner: Name two moves that make an angry call worse, and the one condition that lets you end it.

Never argue, deny, dismiss, or judge. Listen to the complaint, stay positive, and pull in a supervisor when you need help. If the caller turns abusive or threatening, you may hang up.

Afterward, keep it off social media. Venting in public invites scrutiny. Company policy decides what you share.

BPC270 · 11.3
File systems

Every OS signs its disks in its own format.

Windows

  • NTFSJournaling, snapshots, security, indexing, dynamic disks.
  • ReFSLarge storage and data integrity.
  • FAT32 / exFATThe file allocation tables.

Linux

  • ext4The workhorse Linux format.
  • XFSThe extended file system.

macOS

  • APFSApple’s proprietary file system.

Crossing over: macOS can read an NTFS disk but cannot write to it.

BPC270 · 11.3
Check: Sign the disk

Commit: match each file system to its OS.

  1. ext4
  2. APFS
  3. ReFS

With a partner: Name the operating system behind each one, plus the one-way trick macOS plays with NTFS.

Linux, macOS, Windows. ext4 belongs to Linux, APFS to macOS, and ReFS to Windows, built for large storage and data integrity. And macOS can read an NTFS disk but cannot write to it.
