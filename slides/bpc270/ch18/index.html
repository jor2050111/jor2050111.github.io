Lesson 18.2 · Wi-Fi Protected Access

Each WPA generation retired a weaker lock.

WPA

Do not use
  • TKIP · RC4 traffic encryption
  • The lock every generation since has replaced.
→

WPA2

Minimum today
  • AES replaces RC4
  • CCMP replaces TKIP
  • PSK: a passphrase joins the network
→

WPA3

Pick for MESA‑OFFICE
  • SAE replaces the 4-way handshake
  • AES GCMP replaces CCMP
  • Personal mode keeps the passphrase
  • Keys change with every transmission

AES, a symmetric algorithm, does the encrypting under both WPA2 and WPA3. Forward secrecy means a stolen key cannot unlock recorded traffic.

Lesson 18.3 · Home router setup

Mount it high, wire the WAN, then dump the default password.

  1. Place it high and central. Highest elevation avoids furniture and human interference. Centered gives the best coverage.
  2. Wire it. ISP connection into the WAN port, then plug in power.
  3. Sign in. The web-based utility or wizard walks the setup.
  4. Change the default password. First move after login.
  5. Update the firmware. Web GUI menu or manual download. Keep power on the whole time.
