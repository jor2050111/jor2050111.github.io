BPC270 · 13.1
Check: The optimize pass

Commit: PC-207’s C: drive is an SSD. What does Optimize do?

Drive type: SSDTool: Defragment and Optimize

With a partner: Does the tool shuffle data into contiguous clusters, or something else? Why does the answer depend on the drive type?

A trim, not a defrag. On an SSD the tool runs a trim operation to reduce cell degradation. Reorganizing data into contiguous clusters only pays off on a spinning HDD.

Get around

dir lists, cd moves, a letter changes drives.

C:\Users> cd ..        :: up one level
C:\> dir              :: list what lives here
C:\> D:               :: jump to another drive
D:\> cd \             :: back to the root
dir /o: n s e ddir /t: c a wdir /a: r h s a

Three switch families ride on dir. Run dir /? and read what each letter does.
