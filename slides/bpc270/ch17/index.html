BPC270 · 17.1
Check: Set the bits

Commit: rwx r-x r-x becomes which number?

Read counts 4Write counts 2Execute counts 1

With a partner: Work the three sums. Then name the command that applies the result, and the one that changes the owner.

755, applied with chmod. 4+2+1 makes 7, and 4+1 makes 5 twice, so the dash counts zero. chmod sets the mode, chown changes the owner, and ls -l shows the letters to verify.
