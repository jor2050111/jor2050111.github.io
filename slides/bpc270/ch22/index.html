A script is a checklist that runs itself.

A series of commands executed in order, written for one OS, usually inside an IDE.

Web content and apps.

.pyPython

Basic script constructs

Five constructs build every script you will read.

  • CommentsNotes the compiler or interpreter never reads.
  • VariablesHold a value the script reuses.
  • BranchesChoose a path from a condition.
  • LoopsRepeat steps until told to stop.
  • OperatorsCompare and combine the values.
