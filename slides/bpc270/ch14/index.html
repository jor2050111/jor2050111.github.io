Past the gateway

Four commands cover everything past the gateway.

  • tracertRound-trip time per hop. Watch where the path slows.
  • pathpingLatency and packet loss per hop, in one report.
  • nslookupName service records for a domain: A, AAAA, MX, NS, PTR, CNAME.
  • netstatActive TCP and UDP connections. The -b switch names the process on each port.
:: Ask Google's public DNS for the comptia.org mail servers
C:\> nslookup -type=MX comptia.org 8.8.8.8

The rest of the toolkit

Assistance is invited. Administration signs in.

The user stays present

  • Remote AssistanceInvite only. Chat plus remote control. Ephemeral ports 49152-65535.
  • Quick AssistRides HTTPS on TCP 443. No firewall changes.

Both still need the user for UAC confirmations.

No user at the desk

  • WinRMSOAP management calls over HTTP or HTTPS. Scripts well in PowerShell.
  • SSHTCP 22. Encrypted. Password or key sign-in.
  • SPICERemote display for VMs. Kerberos sign-in, TLS on the wire.

Off site, a VPN builds an encrypted tunnel to internal systems through the VPN gateway. The rest of the toolkit rides inside it.

TeamViewer · LogMeInTeams · ZoomAirDrop · Nearby Sharing · Nearby ShareRMM · MDM · EDR

BPC270 · 14.4
First moves

Match the symptom to its first move.

  • No OS foundchkdsk and bootrec from the prompt. diskpart checks the active partition.
  • GUI never loadsCheck the monitor, port, and input. Boot to Safe Mode.
  • BSODResearch the on-screen details, or scan the QR code.
  • App crashesUpdate first. No change? Uninstall and reinstall.
  • Service will not startSet it to start automatically.
  • Clock driftsReplace the CR 2032 battery, then sync to an NTP server.

With a partner: Name the two repair commands you would run from the prompt, and the tool that verifies the system partition is active.

chkdsk and bootrec, then diskpart. chkdsk checks the disk, bootrec repairs the boot records, and diskpart confirms the system partition is set to active. No rewind tool fixes a boot record.
