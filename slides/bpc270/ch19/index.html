BPC270 · 19.1
End user and permission hygiene

Shrink what an attacker can reach.

Daily habits

  • Log off, or lock with ⊞ Start L when you step away.
  • Secure critical systems from theft.
  • Keep PII and passwords out of sight.
  • Use a password manager.
  • Least privilegeThe fewest admin accounts possible.
  • UAC / sudoKeep the elevation gates enabled.
  • Unused radiosWi-Fi, Bluetooth, NFC: off unless needed.
  • Extra servicesDisable file and print services the system does not need.

Every idle service and extra admin account is one more door. Close what you do not use.

BPC270 · 19.2
Encryption at rest

Encrypt one file, or seal the whole disk.

EFS

  • Protects data at rest, file by file.
  • The Advanced button of the file’s property dialog.

BitLocker

  • Full disk encryption, password protected.
  • Recovery key backed up off the protected disk.
  • A TPM can be used. To Go covers removable drives.

Neither ships in the Home edition. Check the edition before you promise encryption.

BPC270 · 19.4
Best practices for malware removal

Seven steps, in order. Contain before you clean.

  1. 1Investigate and verify the symptoms.
  2. 2Quarantine the infected system.PUA:Win32/SyntosecContain
  3. 3Disable System Restore.
  4. 4Remediate: update anti-malware, scan, remove.
  5. 5Schedule scans and run updates.
  6. 6Re-enable System Restore, create a restore point.
  7. 7Educate the end user.

Inside the quarantine

  • Quarantine is not removal.
  • Isolate from the network: physical if possible, logical at minimum.
  • Heavier tools: scan from another system, WinRE, or reinstall (erase, repartition, reinstall).
  • Backups can carry the malware too. Evaluate before restoring.

Verify, quarantine, disable System Restore. Then scan. Isolation stops the spread, and a saved restore point could carry the infection forward. Quarantine only isolates: the malware sits inside until remediation removes it.
