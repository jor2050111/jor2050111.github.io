Checkpoint 2 · POST

When the screen stays blank, POST speaks in beeps.

One long, two short: a code, not a noise. The maker’s table says what it means.

POST fails? Work this list.

  • Verify any recent changes
  • Reseat cables and connections
  • Suspect faulty interfaces
  • Verify the PSU
  • Last: CPU or firmware faults

Inside setup

BIOS types. UEFI points and clicks.

BIOS

Basic input/output system. Keyboard only: the menus print their own key guide.

UEFI

Unified extensible firmware interface. Mouse and keyboard, graphical, modern.

Both do the same job: configure the machine before any OS loads.

BPC170 · 4.1
Check: Close the ticket

Commit: what closes ticket #4088?

  1. Replace the fixed disk. It no longer boots.
  2. Eject the flash drive and put the fixed disk first in the boot order.
  3. Reinstall Windows from recovery media.
Option 2, and nothing was broken. Eject the stick, set the fixed disk first, save, and reboot. Windows loads. The method beat the parts cannon: no new drive, no reinstall, no cost.

More setup dials

Setup holds more dials than boot order.

  • USB permissionsDisable controllers, adapters, or ports: one at a time or all.
  • Fan controlTrade speed for noise. Sensors watch the temperature.
  • Supervisor passwordLocks the setup menus themselves.
  • User passwordLocks the whole system at power-on.

RAID 0 warning: no redundancy. One lost disk ends the volume. It trades safety for speed.

Before any disk moves

  1. Back up the array first.
  2. Read the controller’s boot alert.
  3. Hot swap only the red-lit disk.

BPC170 · 4.3
Physical clues

The board keeps a diary. Learn to read it.

  • Scorch marksA spike or short left heat behind.
  • Swollen capacitorsBulging tops mean the board is failing.
  • Spills and dirtLiquid and grime corrode contacts.
  • Bent pinsCareless connector insertion leaves marks.
CR2032
Clock wrong at every boot?

The coin cell feeds the real-time clock and preserves settings. Swap it.

BPC170 · 4.3
Check: The dying projector

Commit: the projector quits mid-lecture. Why?

With a partner: It shuts itself down, then powers back up later. Name your two best suspects, and the one thing you must do before touching the bulb.

Heat first, bulb second. Blocked vents overheat a projector into protective shutdown, and a worn bulb can blow outright. Either way, let it cool fully first: the bulb runs hot enough to injure and shatters easily when hot.
