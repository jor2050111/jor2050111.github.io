BPC170 · 6.2
When the lease fails

An address that starts 169.254 means the lease never came.

  • Staticyou type all four settings by hand.
  • DHCPthe service fills the settings automatically.
  • APIPAthe PC self-assigns 169.254.0.1-169.254.255.254.

Read it as a symptom: see 169.254 and check the DHCP server and the cable before anything else.

Check: Pick the door

Commit: which port answers each job?

  1. Serve a secure web page.
  2. Turn www.example.com into an address.
  3. Remote-control a Windows desktop.
  4. Lease an address to a new host.
1: 443, HTTPS over TCP. 2: 53, DNS over UDP. 3: 3389, RDP. 4: 67/68, DHCP over UDP. The pattern: pages need TCP’s handshake. Tiny lookups and leases ride UDP.
