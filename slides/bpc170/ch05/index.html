Warm-up: The hidden path

What stands between your keyboard and the server?

48 bits, written in hex, burned into every NIC: Ethernet, fiber, or wireless.

See your own: ipconfig /all on Windows, ip addr on Linux.

Check: The unknown server

Commit: where does the frame go now?

CAM table holds port 12 onlyServer’s MAC: not listedFrame must be delivered

With a partner: Predict the switch’s move, and what finally teaches it the server’s port.

It floods. The frame copies out of every port except port 12. The server answers, the switch reads that reply’s source address, and the table gains the server’s port. The next frame goes straight there.

Check: Desk 12 goes dark

Desk 12 is dead. Pick your first tool.

  • Cable testerLEDs prove each wire pair, end to end.
  • Toner probeFinds one cable inside a bundle.

No link lightPanel labels missing48 identical cables

Commit first: Which tool comes out first, and why?

Toner probe first. The missing label is the blocker: tone the D12 run to find its panel port. Then the cable tester checks every pair of the run. If the run passes, the loopback plug clears the port itself.

BPC170 · 5.4
Wireless

An access point turns the LAN into radio.

The AP bridges 802.11 radio onto the cabled LAN. Its own MAC becomes the network’s BSSID: the same 48-bit format from Desk 12.

2.4 GHz5 GHz6 GHz
1234567891011

On 2.4 GHz, only channels 1, 6, and 11 stay clear of each other.

Slow Wi-Fi, crowded scan? A Wi-Fi analyzer reads signal strength and interference. The fix: move to a clear channel.
