# CIS156: Your first GUI with tkinter

Live online code-along deck, 19 slides, 60 minutes. Palette `midnight-gold`.
Motif: a diner counter with a service bell (the bell is the event, the server
is the event loop). Deck styles live in `chapter.css` beside the shared runtime.
Code on the slides is copied from the tested step 1-4 demo files.
Illustrations in `assets/` are Codex renders. Prompts are in
`assets/image-prompts.md`. Check with `./scripts/validate-decks`.
