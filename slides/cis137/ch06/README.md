# CIS137 Chapter 6: Iterative Refinement

Open `index.html` in a modern browser or use a local web server.

The completed deck uses a version-ledger treatment (faint notebook
ruling, a double gold margin rule, version numerals climbing the margin,
a v1 tag as the brand glyph) and the `canvas-light` palette. It links
the shared CIS137 components in `../course.css`. The four generated
illustrations live in `assets/`, with their prompts in
`assets/image-prompts.md`. Run the validator from the repository root:

```bash
./scripts/validate-decks
```
