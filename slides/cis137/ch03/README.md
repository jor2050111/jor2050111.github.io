# CIS137 Chapter 3: Research, Creative Work, and Responsible Use

Open `index.html` in a modern browser or use a local web server.

The completed deck uses an editor's paste-up table treatment (pasted strips, a red pencil, redaction bars) and the `canyon-sand` palette. Teaching figures (the research brief ledger, the caveat ledger, the disclosure builder, the privacy sort) are built in HTML and CSS. The four generated illustrations live in `assets/`, with their prompts in `assets/image-prompts.md`. Run the validator from the repository root:

```bash
./scripts/validate-decks
```
