# CIS137 Chapter 8: Governance, Privacy, and Content Ownership

Open `index.html` in a modern browser or use a local web server.

The deck uses a rulebook-shelf treatment (four binders for law, policy, guidance, and ethics, a highlighter stroke, a signature rule) and the `canyon-sand` palette. Teaching figures (the sorting shelf, the EU tier gates, the dated tracks, the reading sheet, the delete timeline, the poster layers, the AI Use Policy card) are built in HTML and CSS on top of `../course.css`. Four AI-generated illustrations live in `assets/`, with their prompts in `assets/image-prompts.md`. Run the checks from the repository root:

```bash
./scripts/validate-decks
python3 scripts/check-cis137-deck.py ch08
```
