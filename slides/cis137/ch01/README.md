# CIS137 Chapter 1: What Artificial Intelligence Is

Open `index.html` in a modern browser or use a local web server.

The completed deck uses a sorting-desk treatment (index tabs, three
trays, a round date stamp) and the `phoenix-classic` palette. It is the
first deck to link the shared CIS137 components in `../course.css`
(chat surface, reading marks, passes, verdict chips, artifact card,
stamps, before-and-after, framed illustrations). The four generated
illustrations live in `assets/`, with their prompts in
`assets/image-prompts.md`. Run the validator from the repository root:

```bash
./scripts/validate-decks
```
