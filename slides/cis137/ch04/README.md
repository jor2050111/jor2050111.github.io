# CIS137 Chapter 4: Prompt Basics and Prompt Types

Open `index.html` in a modern browser or use a local web server.

The deck uses a card-catalog treatment (five divider tabs, one per part of a prompt, faint card ruling, a drawer front, a card-tab glyph) and the `twilight-data` palette. It links the shared CIS137 components in `../course.css` and keeps one color per prompt part (Role, Task, Context, Format, Constraints) across tags, stacks, and response marks. The four generated illustrations live in `assets/`, with their prompts in `assets/image-prompts.md`. Run the validator from the repository root:

```bash
./scripts/validate-decks
```
