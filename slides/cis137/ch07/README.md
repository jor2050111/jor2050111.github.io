# CIS137 Chapter 7: Accuracy and Bias

Open `index.html` in a modern browser or use a local web server.

The completed deck uses an inspection-station treatment (conveyor
rollers, a hanging lamp, a gate glyph) and the `midnight-gold` palette.
The audit mechanisms (the four verdict gates, the 11-claim board, the
cause routing, the paired-test lanes, and the Audit Report card) are
built in HTML and CSS. The four generated illustrations live in
`assets/`, with their prompts in `assets/image-prompts.md`. Run the
validator from the repository root:

```bash
./scripts/validate-decks
python3 scripts/check-cis137-deck.py ch07
```
