# CIS137 Chapter 2: How Generative AI Works and Where It Fails

Open `index.html` in a modern browser or use a local web server.

The completed deck uses a next-word rail treatment (word tiles, a
context-window frame, a die for chance) and the `midnight-gold`
palette. Mechanism figures (the next-word slot, the token split, the
sliding window, the fork, the error rows, the blended citation, and
the four-step verify strip) are built in HTML and CSS. The four
generated illustrations live in `assets/`, with their prompts in
`assets/image-prompts.md`. Run the validator from the repository root:

```bash
./scripts/validate-decks
```
