# CIS137 Chapter 5: Strategies That Make Prompts Work

Open `index.html` in a modern browser or use a local web server.

The completed deck uses a tune-up bench treatment (a nine-switch panel
for the Prompt Strategy Checklist, a word-count gauge, a toggle-switch
glyph) and the `golden-hour` palette. Mechanism figures (the switchboard,
the fact plugs, the rule-by-rule checks, the grounding gate, the repair
ladder) are HTML and CSS built on the shared components in
`../course.css`. The four generated illustrations live in `assets/`,
with their prompts in `assets/image-prompts.md`. Run the validator from
the repository root:

```bash
./scripts/validate-decks
```
