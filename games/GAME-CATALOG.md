## Rotation rule

Order games by their place in the course, not creation date. Compare a new
game with the closest existing or reserved game before it and after it.
Chapters without games do not reset the sequence. When filling a gap, respect
both neighbors. Never ship two consecutive games in the same course with the
same primary family. If a new explicit user request conflicts, identify the
conflict and obtain a decision instead of silently relabeling the game.

BPC170 Chapter 04 uses Strategy / management, following Chapter 03's Creative
sandbox and Chapter 02's Puzzle. The next BPC170 game must use another primary
family. Different courses have independent sequences.

## Classify by the dominant action

| Family | Typical loop | Boundary |
| --- | --- | --- |
| Puzzle | Arrange, match, deduce, route, or allocate toward a fixed solution | Spatial, connection, sorting, and escape-room puzzles still belong here |
| Narrative adventure | Choose an action in a story and explore its consequences | A chain of fixed-answer questions in story clothing is not a new mechanic |
| Strategy / management | Manage changing conditions and tradeoffs over several turns | A fixed allocation board with one target is still a puzzle |
| Creative sandbox | Build or alter something, observe behavior, improve it | Multiple meaningful outcomes, not a disguised single correct arrangement |
| Exploration / discovery | Investigate a space or system and reveal relationships | The exploration itself carries the learning, not merely finding quiz cards |
| Arcade / action | Control movement or aiming with immediate causal feedback | Must offer accessible controls and relief from precision or speed demands |

These are design aids, not an exhaustive list. Add another family when its
loop is meaningfully different. Record the actual loop in the plan and the
catalog. A new theme, scoring system, or question set alone does not qualify.

Prefer the least recently used suitable family beyond the hard neighbor rule.
Do not sacrifice the concept fit just to rotate. If no strong fit emerges,
present the tradeoff with two concrete alternatives.
