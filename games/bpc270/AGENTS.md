# BPC270 game workflow

Read the parent [AGENTS.md](../AGENTS.md), then the shared
[educational-game-builder skill](../educational-game-builder/SKILL.md),
[course context](COURSE.md), and [catalog](../GAME-CATALOG.md).

This folder is a workflow scaffold. No game, chapter, or mechanic is selected.
For a future BPC270 game request, ask only for the chapter if it is missing.
For setup or review, do not ask for a chapter or begin a game.

Use the source map in COURSE.md. BPC270 does not restart at Chapter 02.
Shared Module 1 is a special case, and Chapter 24 has no local deck in the
verified inventory. Recheck sources before deciding how either should map.

Follow the shared workflow and templates without copying them into this
folder. Record mechanics in the shared catalog, using BPC270's own sequence.
Do not inherit BPC170's next-family restriction or reserve its retained ideas.

Default delivery is local. A push to this repository's main branch publishes
through GitHub Pages. Require authorization for the specific game's release.
Resolve any Canvas destination separately when explicitly requested.
