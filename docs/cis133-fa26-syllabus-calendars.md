# CIS133 Fall 2026 — Student Calendar Tables

Drop-in tables for the last page of each syllabus. Due-date pattern follows the
course convention: **discussions due Thursday**, **everything else due Sunday**.

The textbook carries six graded discussions (0.5, 3.7, 5.7, 7.7, 9.7, 11.7), so
the Thursday column is populated in six weeks rather than all of them. Blank
means no discussion that week, not a missing entry.
